Asyntai AI Chatbot
==================

Thank you for installing Asyntai AI Chatbot.

Get started:

1. Open the Command Palette (Ctrl+Shift+P, or Cmd+Shift+P on macOS).
2. Run "Asyntai: Set API Key" and paste your API key.
   Find the key in your Asyntai dashboard under Settings, API.
3. Run "Asyntai: Ask My Chatbot" and type a question.

Every command starts with "Asyntai:" in the Command Palette.

Guide: https://asyntai.com/documentation/integrations/sublime-text/
